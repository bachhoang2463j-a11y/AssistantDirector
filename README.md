# Assistant Director（副导演）

> SillyTavern（酒馆）AIRP 跑团的**世界模拟器**——让世界不等玩家行动也在运转。酒馆助手（TavernHelper / JS-Slash-Runner）**悬浮窗脚本插件**，单 JSON 文件形态（AiRadio 同构，非正则替换的内联 iframe 页面）。

**当前版本：V0.3.2** ｜ 状态：S7 世界引擎化重构完成（单一副导演 API 世界推演 + 本地骰每楼推进 + 遇敌概率档案 + 随机遭遇掷骰 + 防连战锁 + 报纸 tab 化 UI）

---

## 一、这是什么

玩家做调查时正文 AI 几乎不会让他失败；上下文塞满后它会忘掉世界书里的派系与伏笔；而"世界在背后做什么"——各方势力今晚干了什么、局势正在升温还是缓和——全靠正文 AI 即兴且事后就忘。副导演插件把世界状态接过来：

- **世界推演**（单一副导演 API，每 3 楼心跳 + 重大事件强制推）：增量修订世界状态 `$ad_world`——派系暗线三态（公开征兆/幕后真相/接触/圈套/间谍）+ 事件链（萌芽→发酵→逼近→爆发→平息）+ 风声（私下/流传/公开）+ **遇敌概率档案**（heat 冷热 + spots 地标级 + districts 大区级）；
- **本地骰**（每楼零 LLM，仿世界引擎）：事件链阈值骰推进/受挫/晋级（conflict 到爆发阶段注入"⚠ 临近冲突"提醒）、风声安静超时按递增概率消散、swipe 幂等守卫；
- **随机遭遇掷骰**（S6）：用户发送输入时本地掷骰，命中即把强制开战指令以用户身份追加进本楼输入——概率 = `spots > districts > 玩家设置` 三级兜底 + 冷热修正（heat + 本地事件张力），**防连战锁**每推演周期最多一场；
- **叙事阻力**：禁泄清单与调查误导注入——世界的真相需要正确的途径才能抵达；
- **报纸**（公开层）：📰 报纸（派系征兆灰卡/接触即揭）/ ⚡ 事件链 / 📣 风声 三个 tab，态势简报显示当前地点**遇敌几率**与区域氛围。

**V0.3.0 架构原则**：敌人安排与开战方式由**正文 AI** 负责（智力最高信息最全，从世界书图鉴自选）；副导演只做**概率掷骰提醒**与世界状态模拟——程序管数值与节奏，AI 管叙事。

```
正文 AI（最强模型·叙事）  每楼：正文 + 状态栏标记点 + 条件成立时最短 <Combat_block>（敌方自选图鉴词条）
RpgCombat（战斗属地）      Combat_block 轮询 → 图鉴载入/导演兜底 → 建局 → 本地结算
副导演（单一 API·世界）    推演（每3楼心跳/战斗结果·跨日·阶段强制推/手动📡）：$ad_world 增量修订
                          本地骰（每楼零 LLM）：事件链推进 + 风声衰减
                          掷骰（用户发送时）：遇敌概率档案 → 命中即注入强制开战指令（防连战锁）
                          注入：单词条「副导演」= <当前态势>信号级 + <内部导演备忘>世界动态
```

数据闭环：MMS `stat_data`（地点/日期/我方状态）→ 副导演触发检测与概率计算 → 写入世界书词条（`副导演`，at_depth/system/深度0/排序15，MMS 同构）注入正文 AI → 正文打最短 Combat_block → RpgCombat 建局结算 → `$rpg_combat_result` 写回 MMS → 副导演监听结算强制推演（世界状态反映战果）。

## 三、核心设计原则

1. **程序管数值，AI 管叙事**——开战宣告是点名册（Combat_block 只写名字），遇敌概率与节奏是程序掷骰，敌方构成与世界叙事是 AI；
2. **双层信息架构**——玩家看公开征兆（报纸），正文收幕后真相（世界动态注入），成对生成、互不可见对方层；
3. **模拟而非剧本**——事件链/风声/派系动向是状态而非剧情表，本地骰每楼推进、推演每 3 楼宏观修订；
4. **宣告而非生成**——开战是最短 Combat_block，检测建局全是 RpgCombat 程序死活；
5. **开战链路不死锁**——无世界状态时随机遭遇回落玩家设置基线，敌方构成正文 AI 从图鉴自选；
6. **地点不可穷尽**——zoneHit 三通道匹配（整串包含/压缩/切段分段）容忍 LLM 真实写法（复合 zone/括号注记/无分隔符）。

完整协议（世界状态 schema/encounter 概率算法/触发矩阵/注入协议/可见性矩阵）见 **[SPEC.md](SPEC.md)**。

## 五、视觉

- 折叠态 = 贴边电报纸带（竖排 ticker + 未读琥珀脉冲）；
- 展开态 = 报纸增刊面板：报头（GM 按钮行 📡↻🌍📜⚙）→ 栏目导航（📰 报纸 / ⚡ 事件链 / 📣 风声，paper 主题红底白字栏目签）→ 当前所在地态势简报（遇敌几率 + 区域氛围）→ 情报流 → 报尾；
- 视觉基因与 MMS 同源（slate 深底 / 琥珀金 / Courier 打字机 / 1920s 报纸双线框），底注即双层架构的宣言："本报仅刊载街头可见之事 · 真相须由读者自行抵达"。
