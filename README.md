# Assistant Director（副导演）

> SillyTavern（酒馆）AIRP 跑团的**世界模拟器**——让世界不等玩家行动也在运转。酒馆助手（TavernHelper / JS-Slash-Runner）iframe 插件，单 HTML 文件形态。

**当前版本：V0.1（立项）** ｜ 状态：文档阶段，未落码

---

## 一、这是什么

玩家做调查时正文 AI 几乎不会让他失败；上下文塞满后它会忘掉世界书里的派系与伏笔；安排敌人的数值杂活交给 LLM 总出幻觉。副导演插件把这三件事从正文 AI 手里接过来：

- **叙事阻力**：注入禁泄清单与调查误导——世界的真相需要正确的途径才能抵达，不是玩家的愿望；
- **暗线模拟**：次级模型每 10 轮（+事件）推演各派系在背后的行动——玩家在贴边栏读到的是**公开征兆**（"沙蝎近期活动频率降低"），正文 AI 收到的是**幕后真相**（"因警方与黑帮冲突加剧，沙蝎放弃原计划改召教徒研究"），中间的推导距离就是调查空间；
- **战斗初始化**：正文 AI 只打一个 ~30 token 的标记宣告开战，敌方词条匹配、我方数值直连、Combat_block 组装全部由程序完成——**正文 AI 在整条数值链路上零接触**。

```
正文 AI（最强模型·叙事）  每楼：正文 + 【状态栏标记点】 + 条件成立时【战斗标记点丨我方:…丨敌方:…】
程序（数值与执行）        标记 → 词条展开 + 状态栏直连 → 组装 → 直推战斗前端建局
副导演（次级模型·世界）    暗线 / 派系地盘与戒备修正 / 来袭预约（LLM 慢思考埋雷，程序快执行起爆）
```

## 二、三件套生态

| 插件 | 目录 | 职责 |
| :--- | :--- | :--- |
| MiniMapStatus（状态栏） | `D:\Project\MiniMapStatus` | 状态维护：数值/物品/地图/固定名册/每日结算 |
| RpgCombat（战斗前端） | `D:\Project\RpgCombat` | 战斗执行：纯本地数值引擎，LLM 只写台词 |
| **AssistantDirector（副导演）** | 本项目 | 世界模拟：暗线/敌人放置/战斗初始化 |

数据闭环：状态栏（`stat_data` 我方数值）→ 标记组装 → 战斗前端建局 → `$rpg_combat_result` 程序写回状态栏 → 副导演监听结算触发事件快报。

## 三、核心设计原则

1. **程序管数值，AI 管叙事（完全体）**——正文 AI 做的每个动作都是选择题，不是填空题；
2. **双层信息架构**——玩家看公开征兆，正文收幕后真相，成对生成；
3. **模拟而非剧本**——敌人放置是"驻防态"（谁/多少/什么戒备/怎么反应），遇敌是语义涌现，不枚举触发器；
4. **宣告而非生成**——开战是 ~30 token 的标记，组装是程序死活；
5. **开战链路不死锁**——菜单命中 → 修补生成 → 图鉴近似，三级容错。
