# Assistant Director（副导演）

> SillyTavern（酒馆）AIRP 跑团的**世界模拟器**——让世界不等玩家行动也在运转。酒馆助手（TavernHelper / JS-Slash-Runner）**悬浮窗脚本插件**，单 JSON 文件形态（AiRadio 同构，非正则替换的内联 iframe 页面）。

**当前版本：V0.2.9** ｜ 状态：S0~S5 全部落地（S4 完全体阶段揭示 + S5 名册/墓碑），注入走世界书词条（XML 模板 · 双独立开关）；S6 用户自测

---

## 一、这是什么

玩家做调查时正文 AI 几乎不会让他失败；上下文塞满后它会忘掉世界书里的派系与伏笔；而"世界在背后做什么"——敌人在哪、什么戒备、各方势力今晚干了什么——全靠正文 AI 即兴且事后就忘。副导演插件把这三件事接过来：

- **叙事阻力**：注入禁泄清单与调查误导——世界的真相需要正确的途径才能抵达，不是玩家的愿望；
- **暗线模拟**：暗线位模型按天推演各派系在背后的行动——玩家在贴边栏读到的是**公开征兆**（"仓库区彻夜货运，木箱空得反常"），正文 AI 收到的是**幕后真相**（"伦道夫疑似清空据点，仅可经港口风向渗透，禁止直接揭示"），中间的推导距离就是调查空间；
- **态势卡片**：每个有戏的地点一张驻防卡（谁/多少/什么戒备/怎么反应 + 敌方菜单），每楼配发给正文 AI——新地点由态势位小模型即时产卡，每日报告全量复审。

```
正文 AI（最强模型·叙事）  每楼：正文 + 状态栏标记点 + 条件成立时最短 <Combat_block>（只写名字）
RpgCombat（战斗属地）      Combat_block 轮询 → 图鉴载入/导演兜底 → 建局 → 本地结算
副导演（双模型·世界）      暗线位（次高智力，天级）：派系推演/叙事阻力/预约埋雷/卡片复审
                          态势位（快速小模型，随地点）：新地点即时产卡
                          程序（每楼零调用）：卡片匹配配发/注入/引爆检查/贴边栏
```

## 三、核心设计原则

1. **程序管数值，AI 管叙事（完全体）**——开战宣告是点名册（Combat_block 只写名字），我方数值 MMS 直连、敌方数值图鉴/导演兜底；
2. **双层信息架构**——玩家看公开征兆，正文收幕后真相，成对生成、互不可见对方层；
3. **模拟而非剧本**——敌人放置是"驻防态"，遇敌是语义涌现，不枚举触发器；
4. **宣告而非生成**——开战是最短 Combat_block，检测建局全是 RpgCombat 程序死活；
5. **开战链路不死锁**——态势注入是增强层，未命中地点照样开战（图鉴 + 兜底链）；
6. **地点不可穷尽**——AIRP 地点自由涌现，态势内容本质是语义判断归 LLM，程序只匹配配发校验。

完整协议（开战通道/态势卡片双轨/暗线 schema/触发矩阵/注入协议/可见性矩阵/单 JSON 结构）见 **[SPEC.md](SPEC.md)**。
